# Sorting Algorithm for Integer Arrays

We implement 4 sorting algorithms for integer arrays.

## Bubble Sort

The Bubble Sort algorithm sorts the array in ascending order.

The algorithm is implemented in C.

## Radix Sort

The Radix Sort algorithm sorts the array in ascending order digit by digit.

The algorithm is implemented in C.

## Heap Sort

The Heap Sort algorithm sorts the array in ascending order using a binary heap.

The algorithm is implemented in C.
